# Capturas de pantalla

Sube aquí las capturas de Roblox Studio para revisar la pista y los pianos.

Formatos recomendados: PNG o JPG.

Idealmente incluye:
- Una captura de la pista completa desde arriba.
- Una captura cercana de cada curva donde los pianos se vean mal.

No subas aquí archivos del proyecto ni modifiques otros archivos.
